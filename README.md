# El Mejor de

> ¿Sos el mejor de tu pueblo? Demostralo.

**El Mejor de** es una web app de minijuegos y retos diarios para competir con amigos, conocidos y con todo tu lugar: podés ser **el mejor de tu pueblo, de tu ciudad, de tu provincia, del país… o del mundo**. Se juega desde el navegador, sin descargar nada.
